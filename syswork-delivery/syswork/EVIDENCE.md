## How the captures were made

The server was started for real and driven over HTTP with `curl`. The
screenshots are headless Chromium against that running server, not mockups. The
intermediate states in `02-` and `04-` were replayed in throwaway git worktrees
at the relevant commit, so each capture shows the code as it actually stood at
that moment rather than the finished version with parts hidden.

## Two things to be straight about

**The review was agent-run.** The finding in `refundsplit/docs/REVIEW.md` was
produced by the same agent that wrote the fix, on a second pass instructed to
attack the change. The finding is real — `04-order-dependence-fails.txt` is the
proof, generated by running the code — but a model reviewing its own work is not
human review. The document says so at the top, and the runbook tells you to say
so out loud. Before you present it, read the diff and confirm the finding
yourself.

**The timings measure the mechanical part only.** The wall-clock figures in
`ADOPTION.md` are commit timestamps from one uninterrupted session. They exclude
building the baseline application, capturing this evidence, and writing the
session materials. They include no human review time whatsoever. They are not a
productivity claim and should not be presented as one.
